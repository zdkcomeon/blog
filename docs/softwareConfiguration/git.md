### Idea配置GitBash
在idea控制台中可以直接使用git Bash，无需进入软件目录使用git.bash，简化流程，提高开发效率


### Idea指定git.exe
告诉idea我们本地安装的git路径，可以给咱们下载的项目自动使用本地git进行项目管理
