## 建议阅读顺序

1. 从 [Java 学习资料](./Java/八股文.md) 入手，建立语言与运行时基础。
2. 补充 [MySQL](./mysql/)、[计算机网络](./computer-networks/) 和 [操作系统](./os/) 知识。
3. 进入 [Spring 与数据库访问](./frameword/)，结合项目阅读官方文档。
4. 用 [实践笔记](../tips/) 中的测试、编码和服务调用记录串联知识。
