# trae.com 交互分析与博客首页改造

参考：[Trae — Trusted Fool](https://www.trae.com/)、[Resources](https://www.trae.com/resources)。分析时间：2026-11-05。

用户已确认参考原链接的扑克牌创意站。以下基于在线页面、公开 HTML、CSS 和页面脚本的检查；当前工具未提供可操作的浏览器，尚未进行实际点击、声音试听或截图比对。视觉状态与交互参数取自源码，行为描述应与浏览器实测区分。

## 站点结构

首页是全屏黑色舞台，核心是一张白色扑克牌，而不是常规的导航、横幅和长列表。Resources 是独立的工具链接页；主要内容通过首页卡牌内部状态展示。

| 入口 | 页面脚本中的内容与操作 | 博客中的对应入口 |
| --- | --- | --- |
| 主牌 | 初始身份展示，点击翻面，展开四张花色牌 | 作者身份牌，点击查看作者简介 |
| 黑桃 / View Work | 案例卡片，桌面在主牌周围展开，手机滑动浏览 | 学习资源，打开最近学习文章与专题目录 |
| 方块 / The Process | 工作流程拆成连续卡片，逐层进入并返回 | 工程实践，进入故障排查、开发与性能优化笔记 |
| 梅花 / Manifesto | 三个篇章构成的理念卡组 | 开发工具，整理安装、配置与日常工作流 |
| 红桃 / Hire Trae | 联系表单，提交到站点自己的 `/api/contact` | AI 实践，打开规则、Agent 与编程协作笔记 |
| Resources | 工具链接、提示词文件下载与复制 | 文档地图，以及页脚的分类、标签和时间线 |
| 问号入口 | 站点介绍浮层 | 主牌背面的作者介绍与“认识一下”入口 |

## 视觉语言

- **舞台与牌面分离**：黑色背景、白色牌面、少量红色花色。中心留白和极强明暗对比使卡牌成为焦点。
- **真实的牌面比例**：源码中的主牌为 236 × 322，圆角 14px，搭配边框、背面和阴影构建立体感。
- **花色承担导航语义**：四种花色与四个栏目对应，悬停时给出文字说明，不只是背景装饰。
- **排版反差**：等宽字体用于提示与说明，装饰字体用于身份，标题字母与扑克牌花色间存在逐字替换动效。
- **局部细节**：主牌存在跟随指针的彩色反光、循环提示条、点阵背景和边缘暗角。

## 交互与动效逻辑

1. **进入舞台**：主牌处于初始正面，提示点击。卡面局部反光随鼠标位置变化。
2. **指针倾斜**：根据鼠标相对于主牌中心的位置计算旋转，源码上限约为 ±19°；弹簧参数为 stiffness 300、damping 30。指针离开后归零。
3. **主牌翻面**：桌面使用 1000px 透视和约 600ms 的 Y 轴翻转，正反面使用背面隐藏。手机使用淡入和位置变化。
4. **花色发牌**：四张牌依次出现，扇形角度为 -20°、-7°、7°、20°。悬停时抬起并显示栏目文字。
5. **内容展开**：选择花色后进入对应卡组，桌面案例可以从中心向四周展开；手机将内容改为滑动卡片。
6. **返回逻辑**：页面维护访问过的卡牌堆栈，可关闭当前卡片或回到初始主牌。首页交互是一个小型状态机。
7. **声音**：脚本包含背景循环音乐、抽牌和翻牌音效，以及静音状态；实际自动播放仍取决于浏览器策略。
8. **响应式**：源码以 768px 为手机切换点，使用更轻的动画和手势。原站将整个页面锁在视口里并限制滚动。

## 博客的具体实现

博客需要让读者快速找到和阅读真实文章，因此把舞台交互与可滚动的阅读入口结合起来：

- 黑色首屏以现有作者头像和站名构成专属主牌；左侧中文标题直接解释博客用途。点击翻牌展示作者简介，桌面鼠标移动产生轻微倾斜与局部反光。
- 四张扇形花色导航牌与四个专题对应。下方浅色区域展示完整牌组，提供栏目说明和从真实文章中计算出的数量。
- 选择花色打开原生 `dialog`，展示栏目介绍、最近四篇文章和完整专题入口，并可在面板底部切换牌组。原生对话框处理焦点约束、Escape 与关闭后的焦点返回；代码补充遮罩关闭、页面滚动锁和卸载清理。
- 最近随记按日期倒序排列，支持全部、四个专题及生活记录的筛选，每次增加六篇。文章地址、栏目和摘要均复用博客插件，新增文章会自动出现。
- 保留文档地图、全文搜索、分类、标签、时间线、生活食谱和关于作者等入口。文章页面继续使用 Hope 阅读布局。
- 字号与卡牌比例使用响应式布局；手机为单列首屏、两列专题卡和原生折叠菜单，允许正常页面滚动。
- 入场动效通过 CSS 与 `IntersectionObserver` 实现；没有脚本或观察器不可用时，内容默认显示。减少动态效果偏好会停用循环动画、入场动画、翻牌过渡与指针倾斜，翻牌和专题选择功能仍可使用。
- 所有装饰花色对辅助技术隐藏；翻牌、专题按钮与筛选按钮提供可读名称和状态。没有复制参考站的图片、字体、音频或业务接口，也没有新增动画依赖。

## 验证

自动验证：`npm test`（排序、栏目筛选与日期处理三项检查）、`npm run docs:build`（210 个页面生成成功）。生产 HTML 检查确认首页包含四张导航牌、四个专题、六篇最近文章，首页所有站内链接与首屏资源存在，分类、标签、时间线和四个专题目录均生成成功。

浏览器验收清单（待可操作浏览器可用后执行）：

- 桌面主牌翻面、悬停反光与四张扇形牌抬起，专题展开与花色切换。
- 键盘 Tab 顺序、Escape 关闭、对话框焦点返回、搜索输入与搜索结果跳转。
- 筛选切换、加载更多、随机阅读及从文章页返回首页。
- 320px、390px、768px、1440px 宽度无横向溢出；手机菜单与对话框内部可滚动。
- 减少动态效果、文章直达、分类、标签、时间线和站点 `/blog/` 基础路径。
